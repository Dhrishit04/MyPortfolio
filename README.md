# Dhrishit Seal — Portfolio

Personal portfolio of Dhrishit Seal, software engineer and MSc Computer Science student at University College Dublin.

## Run locally

It is a static site with native ES modules, so any local HTTP server works:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Where the content lives

| Content | File |
|---|---|
| Hero, about, experience, skills, footer | `index.html` |
| Featured projects | `DEFAULT_ITEMS` in `flex-carousel.js` |
| Research | `DEFAULT_WORKS` in `works-wheel.js` |
| Images and CV | `assets/` |
